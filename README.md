# 🔍 Privacy Lab — Photo Scanner

> *Privacy is not just a feature — it's the foundation.*

A free, browser-based tool that reveals hidden metadata 
in your photos including GPS location, camera settings, 
device information and more.

## 🌐 Live Tool
[Try it here](https://abiprivacylab.github.io/privacylab-photo-scanner)

## ✨ Features
- 📍 Detects hidden GPS location in photos
- 📷 Reveals camera and device information
- 🕐 Shows date and time metadata
- 🗺️ Opens location directly in Google Maps
- 🔒 100% private — nothing ever leaves your device
- ⚡ No account required, no data stored, ever

## 🎯 Why This Exists
Most people have no idea that every photo they take 
contains hidden data — including their exact home address. 
This tool was built to create awareness and help protect 
people's privacy online.

## 🛠️ Built With
- Pure HTML, CSS, JavaScript
- Zero dependencies
- Zero server calls
- Runs entirely in your browser
